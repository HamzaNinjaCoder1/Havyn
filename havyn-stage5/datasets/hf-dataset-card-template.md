# Havyn SFT dataset — {{VERSION}}

> **Synthetic data. No human contributors. Not a Gold evaluation set.**

## What this is

Training data for the Havyn intent layer. The model converts natural-language
networking requests into Havyn Intent Schema v1 JSON, diagnoses failed
verification evidence, asks clarification questions, and produces structured
enhancement patches. It does not configure devices; the deterministic Havyn
engine owns addressing, compilation and verification.

## Gold exclusion and leakage policy

- `datasets/gold-v1` is private, owner-authored evaluation data. It is **never**
  copied into this dataset, and its prompt hashes are checked against every
  split.
- Leakage checks in `validate_training_split.py` must pass before a freeze:
  no exact duplicate across splits, no family overlap, no Gold prompt hash.
- A frozen dataset is byte-pinned in `FROZEN.json`. Changing any split requires
  a new version and a new freeze.
- The freeze gate refuses to produce this export if the source directory is not
  frozen or has changed.

## Licensing

- Repository code: MIT (see the repository `LICENSE`).
- Dataset: released under MIT for use with Havyn. Because the content is
  synthetic, no human authorship or copyright is claimed over individual
  prompts; the licence covers the compilation and the generation scripts.
- Third-party base models keep their own licences; this dataset does not grant
  rights to any model weights.

## Privacy

No personal data, customer names, real credentials, public IP addresses or
employer-confidential configurations are included. Scenarios are fictional.
If a real contributor dataset (`external-human-v1`) is created later, it is a
separate dataset with explicit consent and a contributor ledger.

## Limitations

- Synthetic scenarios are narrower than real deployments.
- Template prompts are regular in style; naturalness is not the same as a
  human-written request.
- Refusal/ambiguity coverage is limited to the cases the engine and generators
  can name.
- The dataset is not a benchmark of Packet Tracer correctness; that is the live
  gate's job.
